# SquadSense logo

The "Formation dots" mark: eleven dots in a 4-4-2 with one forward circled, meaning your squad and the pick the app points you to. Chosen on 20 November 2026 from four concepts on the design canvas at https://claude.ai/artifact/2FxzC5prKVFBs6iG9L2k13.

| File | Use |
| --- | --- |
| `squadsense-icon.svg` | App icon: navy dots on a lime rounded square. Also the website favicon (`web/app/icon.svg`) and the source for the Mac app icon. |
| `squadsense-mark-on-dark.svg` | The dots alone in lime, for navy or dark backgrounds |
| `squadsense-mark-on-light.svg` | The dots alone in navy, for white or light backgrounds |

Colors are the app's own: lime `#B7F34A` and navy `#0B1220`. The wordmark is "SquadSense" in Space Grotesk Bold with -0.02em letter spacing.

The artwork is drawn on a 64 by 64 grid, so it scales cleanly to any size. For a PNG at 1024 px (the Mac app icon), convert `squadsense-icon.svg` when the Mac app is built.
