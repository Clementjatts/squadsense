# 3D touches: plan

Spec: `docs/superpowers/specs/2026-11-25-3d-touches-design.md`. Carried
out natively in this session (the design approval is the only approval).

1. **Signal palette.** Built, then reverted at Clement's request; only the
   difficulty colors moved into tokens (`--level-1` to `--level-5`).
2. **Pitch depth.** Test first in `web/tests/pitchDepth.test.mts`:
   `rowDepthScale(index, rowCount)` gives 1 for the front row (goalkeeper,
   last) and `1 - DEPTH_SHRINK` for the back row, evenly between. Then
   `BroadcastPitch.tsx` gets a tilted `.bc-pitch-turf` holding the lines,
   rows scaled by `rowDepthScale`, and a captain spotlight.
3. **Terrain data.** Test first in `web/tests/terrain.test.mts`:
   `terrainColumns(ticker, mode, windowLength, myTeamIds)` returns one column
   per club and shown gameweek in the ranked order, with `height` from
   difficulty (a double adds both matches, a blank is height 0), `level`,
   `mine` and a `label` such as "ARS v CHE (H), GW14: Hard".
4. **3D dependencies.** `three` and `@react-three/fiber` (v9, for React 19).
5. **Account scene.** `components/three/FormationScene.tsx`, mounted by
   `AccountStage.tsx` through `next/dynamic` with `ssr: false`; positions
   from `BrandMark`'s dot list, shared through `lib/formationDots.ts`.
6. **Terrain view.** `components/three/FixtureTerrain.tsx` and a Table / 3D
   switch in `FixtureTickerTable.tsx`, hidden under 1101 px.
7. **Check.** `npm test`, `npm run build`, every touched page in the browser
   at 1440 px and 390 px, "Reduce motion" on, no console errors.
8. **Docs.** CLAUDE.md, the checker on every new comment and doc.
